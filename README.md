# 分工

| 組員 | 模組 | 姓名 |
|---|---|---|
| A | 活動發布與狀態管理（兼專案骨架） | |
| B | 首頁活動列表與報名統計 | |
| C | 報名流程與防重複驗證 | |

## 組員 A：活動發布與狀態管理模組

- **資料庫連線**：建立共用的連線設定檔（db.php），供大家使用
- **新增活動**
  - 製作新增活動表單（活動名稱、內容、活動時間、地點）
  - 後端將新活動寫入 `events` 資料表
- **截止報名**（Pro）
  - 在活動列表加上「截止報名」按鈕
  - 點擊後將該活動的 `is_closed` 更新為 1

## 組員 B：首頁活動列表與報名統計模組

- **活動清單**
  - 首頁列出資料庫中的活動（名稱、內容、時間、地點、狀態）
- **顯示報名人數**（Pro）
  - 用 JOIN + COUNT 計算每個活動的報名人數，顯示在活動卡片上
- **截止狀態連動**
  - `is_closed = 1`：按鈕變灰色「已截止」，不能點
  - 開放中：顯示「前往報名」按鈕

## 組員 C：報名流程與防重複驗證模組

- **報名表單**
  - 點擊活動後出現報名頁面，填寫姓名與連絡電話並送出
- **防重複報名**（Pro）
  - 送出前檢查該活動是否已有「同姓名且同電話」的報名
  - 重複則擋下，提示「您已報名過此活動！」
- **查看報名清單**
  - 選擇某個活動後，顯示所有報名者（姓名、電話、報名時間）
